# Зубилиха: газели и ведомости

Страница для телефона: список рабочих по газелям, Word для чатов и Excel-ведомость.

## Как устроено

Всё работает в браузере, своего сервера нет. На GitHub-сайте список дня хранится в браузере телефона (localStorage), его можно сохранить в файл и открыть на другом устройстве.

Общий день для двоих работает на странице в Claude: день, телефоны и отметки лежат в общей базе страницы (`shared/day`, `shared/book`), вход через аккаунт Claude, доступ даёт владелец через «Поделиться» (уровень «Редактор»). Если двое поменяли разное, правки сливаются (`Core.mergeDay`).

- `app/index.html` — интерфейс (вкладки День, Газели, Люди, Файлы).
- `app/core.js` — справочник остановок, разбор текста из ВК, подсчёты, имена файлов.
- `app/gen.js` — сборка Word (библиотека docx) и Excel (ExcelJS) в формате образцов.
- `app/vendor/` — копии библиотек docx 9.5.1, ExcelJS 4.4.0 и html2canvas 1.4.1 (картинка таблицы), чтобы не зависеть от CDN.

## Проверка

```
npm install
npm test
```

Тесты используют только выдуманные фамилии. Реальные списки в репозиторий не кладём.
