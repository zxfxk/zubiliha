# Зубилиха: газели и ведомости

Страница для телефона: список рабочих по газелям, Word для чатов и Excel-ведомость.

## Как устроено

Всё работает в браузере, своего сервера нет. На GitHub-сайте список дня хранится в браузере телефона (localStorage), его можно сохранить в файл и открыть на другом устройстве.

Общий день на GitHub-сайте: если в `app/index.html` заполнен `FIREBASE` (почта общего логина и `firebaseConfig`), сайт спрашивает пароль и хранит день в Firestore (`shared/day`, `shared/book`). Библиотеки Firebase 10.14.1 лежат в `app/vendor/firebase/`. Правила Firestore пускают только вошедших:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /shared/{doc} {
      allow read, write: if request.auth != null;
    }
  }
}
```

На странице в Claude то же самое работает через общую базу страницы: день, телефоны и отметки лежат в общей базе страницы (`shared/day`, `shared/book`), вход через аккаунт Claude, доступ даёт владелец через «Поделиться» (уровень «Редактор»). Если двое поменяли разное, правки сливаются (`Core.mergeDay`).

Раз в неделю, при входе, сайт сам кладёт копию всей общей базы (день, телефоны, отметки, подсчёт за месяц, записи «Что не так» без скриншотов) в ту же базу: `shared/backups` — список, `shared/backup_<id>_<n>` — копия кусками по 100 000 символов. Хранятся 4 последние недельные копии и одна «перед восстановлением». Правила выше их уже покрывают. Восстановить можно на вкладке «День».

- `app/index.html` — интерфейс (вкладки День, Газели, Люди, Файлы).
- `app/core.js` — справочник остановок, разбор текста из ВК, подсчёты, имена файлов.
- `app/gen.js` — сборка Word (библиотека docx) и Excel (ExcelJS) в формате образцов.
- `app/vendor/` — копии библиотек docx 9.5.1, ExcelJS 4.4.0 и html2canvas 1.4.1 (картинка таблицы), чтобы не зависеть от CDN.

## Проверка

```
npm install
npm test
```

Тесты используют только выдуманные фамилии. Реальные списки в репозиторий не кладём.
