# Зубилиха: газели и ведомости

Страница для телефона: список рабочих по газелям, Word для чатов и Excel-ведомость.

## Как устроено

Всё работает в браузере, сервера нет. Список дня хранится в браузере телефона (localStorage), его можно сохранить в файл и открыть на другом устройстве.

- `app/index.html` — интерфейс (вкладки День, Газели, Люди, Файлы).
- `app/core.js` — справочник остановок, разбор текста из ВК, подсчёты, имена файлов.
- `app/gen.js` — сборка Word (библиотека docx) и Excel (ExcelJS) в формате образцов.
- `app/vendor/` — копии библиотек docx 9.5.1 и ExcelJS 4.4.0, чтобы не зависеть от CDN.

## Проверка

```
npm install
npm test
```

Тесты используют только выдуманные фамилии. Реальные списки в репозиторий не кладём.
